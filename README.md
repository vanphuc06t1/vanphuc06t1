## About Me

I'm a software engineer with **15+ years** of experience in development and testing, based in **Ho Chi Minh City, Vietnam**. I've delivered desktop, web, and mobile applications for international clients in the **United States, Singapore, Japan, and South Korea**, and I've led teams of up to 9 engineers.

My strengths span iOS, macOS, Android, Flutter, and React Native, backed by solid grounding in system architecture, MVVM, modular design, Clean Architecture, IoT, BLE, and AWS-based solutions.

- 💼 **Currently:** Principal Software Engineer at FPT Software
- 🚀 **Building:** [Premium IELTS Coach](https://premiumieltscoach.com), a personal IELTS coaching project across web, mobile, backend, and cloud
- 🎯 **Passion:** Turning complex ideas into useful products
- 🤝 **Open to:** new opportunities and collaborations
